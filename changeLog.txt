[EN]
Version 3.4.0
Changes:

Added support for all screen readers: the program now works not only with NVDA, but also with JAWS, Window-Eyes, System Access, and others. nvdaControllerClient64.dll is no longer required
When exporting to ADIF, the program now automatically suggests a filename in the format callsign_date_time.adi (for example, r1bqe_20260617_134502.adi)
Improved ADIF import: the program now automatically detects file encoding, and files exported by BlindLog are imported correctly
All interface messages are now localized. No more English text when using the Russian interface
Fixed internal logging and time zone handling issues
Updated documentation: added sections about QRZ.ru search, operator data, program logs, update process, and ADIF import
Fixed transliteration documentation. It is now correctly stated that the feature is disabled by default

[RU]
версия 3.4.0
изменения:
изменения:

Поддержка всех скринридеров: программа теперь работает не только с NVDA, но и с JAWS, Window Eyes, System Access и другими. Больше не требуется nvdaControllerClient64.dll
При экспорте в ADIF программа автоматически предлагает имя файла в формате позывной_дата_время.adi (например, r1bqe_20260617_134502.adi)
