# Blind_Log

[English version](readme.md)

Blind_Log — настольное приложение для ведения журнала радиосвязей (QSO), разработанное с учетом потребностей незрячих пользователей. Программа написана на Python, использует wxPython и совместима со скринридером NVDA.

## Возможности

* Добавление, редактирование, удаление и просмотр записей QSO
* Экспорт журнала в формате ADIF
* Импорт ADIF-файлов с помощью `adif-io`
* Поиск данных по позывному через QRZ.ru для автоматического заполнения полей `name` и `city`
* Постоянное хранение журнала QSO в SQLite с автоматической записью изменений
* Транслитерация русского текста в латиницу для совместимости с LoTW, eQSL и Club Log
* Автоматическая проверка обновлений через API GitHub Releases
* Англоязычный и русскоязычный интерфейсы на основе JSON-переводов

## Требования

* Python 3.x
* wxPython
* requests
* transliterate
* adif-io
* accessible-output3
* pytest (для тестов)

Установите зависимости из `requirements.txt`:

    python -m pip install -r requirements.txt

## Запуск из исходников

Из корня репозитория:

    python main.py

## Сборка

В репозитории есть `compile.bat` для создания автономного исполняемого файла через PyInstaller.
Он устанавливает зависимости в локальное окружение `.venv` и запускает `PyInstaller Blind_log.spec`.

## Настройки и данные

* Настройки приложения хранятся в `settings.ini`
* Журнал QSO хранится в `blind_log.db` в каталоге программы; черновик незавершённой формы — в `qso_draft.json`
* Файлы локализации находятся в `locales/en.json` и `locales/ru.json`
* Встроенные страницы помощи: `help.htm` и `help_en.htm`
* История изменений: русская версия — `changelog-ru.txt`, английская — `changelog-en.txt`

Экспорт в ADIF создаёт отдельный файл для обмена и резервного копирования; он не нужен для сохранения записей внутри программы. Старый `blind_log_temp.json` может быть перенесён в базу данных при первом запуске новой версии. Рекомендуется периодически экспортировать журнал в ADIF или копировать закрытый файл `blind_log.db` в безопасное место.

## Структура проекта

* `main.py` — точка входа приложения
* `gui.py` — интерфейс wxPython и диалоги
* `controller.py` — связующее звено между UI и бизнес-логикой
* `journal/manager.py` — обработка данных QSO и валидация
* `journal/storage.py` — постоянное хранение журнала и черновика в SQLite
* `exporter.py` — экспорт в ADIF
* `importer.py` — импорт ADIF
* `settings.py` — менеджер настроек и диалог настроек
* `settings/storage.py` — поддержка чтения/записи файла настроек
* `welcome_dialog.py` — диалог первого запуска и приветствие
* `services/updater.py` — проверка обновлений и поток установки
* `qrz_lookup.py` — интеграция с QRZ.ru
* `nvda_notify.py` — уведомления для экранных читалок
