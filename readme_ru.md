# Blind_Log

[English version](readme.md)

Blind_Log — настольный журнал радиолюбительских QSO, рассчитанный на управление с клавиатуры и использование незрячими пользователями. Программа написана на Python с использованием wxPython и совместима со скринридерами, включая NVDA.

## Возможности
- Добавление, редактирование и удаление записей QSO.
- Поиск, сортировка и фильтрация журнала.
- Постоянное хранение журнала в SQLite и автоматическое сохранение черновика формы.
- Импорт и экспорт ADIF, в том числе выборочный экспорт с помощью отметок.
- Поиск данных корреспондента через XML API QRZ.ru.
- Транслитерация русского текста в латиницу, если функция включена.
- Выбор светлой, тёмной темы или оформления по настройкам системы.
- Настройка видимости необязательных полей и языка интерфейса.
- Управление основными действиями с помощью клавиатуры.
- Проверка обновлений через GitHub Releases.

## Требования
Python 3.x, wxPython, requests, transliterate, adif-io, accessible-output3 и pytest.

Установка зависимостей:

    python -m pip install -r requirements.txt

## Запуск из исходников

    python main.py

## Сборка
Для создания автономного исполняемого файла Windows используется `compile.bat`. Скрипт подготавливает локальное окружение `.venv` и запускает PyInstaller с конфигурацией `Blind_log.spec`.

## Настройки и данные
- Настройки: `settings.ini` в каталоге программы.
- Журнал QSO: `blind_log.db` в каталоге программы.
- Черновик незавершённой формы: `qso_draft.json` в каталоге программы.
- Файлы переводов: `locales/ru.json` и `locales/en.json`.
- Встроенная справка: `help/help.htm` и `help/help_en.htm`.
- История изменений: `changelog-ru.txt` и `changelog-en.txt`.

Экспорт в ADIF создаёт отдельный файл для обмена с другими журналами и резервного копирования. Для сохранения записей внутри Blind_Log экспорт не требуется. При первом запуске старый файл `blind_log_temp.json`, если он остался от предыдущей версии, может быть перенесён в базу данных. Для полной резервной копии закройте программу и скопируйте `blind_log.db`.

## Структура проекта
- `main.py` — точка входа приложения.
- `gui/` — окна wxPython, элементы интерфейса, компоновка и клавиатурное управление.
- `controller/` — сценарии работы приложения и команды интерфейса.
- `journal/` — бизнес-логика QSO, операции с записями и SQLite-хранилище.
- `settings/` — менеджер настроек, хранение параметров и диалог настроек.
- `adif/` — импорт и экспорт ADIF.
- `services/` — поиск по QRZ.ru и службы обновления.
- `accessibility/` — уведомления скринридера и навигация по сегментам даты и времени.
- `common/` — общие функции, константы, темы, транслитерация и работа с версией.
- `localization/` и `locales/` — загрузчик переводов и JSON-файлы локализации.
- `help/` — справка на русском и английском языках.
- `instructions/` — документация для разработки.
- `tests/` — автоматические тесты.
- `scripts/` — вспомогательные скрипты.

## Тестирование

    python -m pytest tests -q

Встроенная справка доступна по клавише **F1**.
