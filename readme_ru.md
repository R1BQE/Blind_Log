# Blind\_log

Blind\_log — программа для ведения журнала радиосвязей (QSO), разработанная специально для незрячих радиолюбителей. Интерфейс полностью управляется с клавиатуры и совместим со скринридером NVDA.

## Возможности

* Добавление, редактирование и удаление записей QSO
* Экспорт журнала в формат ADIF
* Импорт ADIF-файлов из других программ (UR5EQF Log, Ham Radio Deluxe и других)
* Поиск данных корреспондента по позывному через QRZ.ru
* Автосохранение сеанса с восстановлением после сбоя
* Транслитерация русского текста в латиницу для LoTW, eQSL, Club Log
* Автоматическая проверка обновлений
* Интерфейс на русском и английском языках

## Установка

1. Скачайте zip-архив с последней версией:
[Скачать последнюю версию](https://github.com/r1bqe/Blind_Log/releases/latest/download/Blind_log.zip)
2. Распакуйте архив в удобную папку.
3. Запустите Blind\_log.exe. Права администратора не требуются.

## Документация

Подробная справка доступна внутри программы по клавише **F1**.
