About the program

Blind_Log is an amateur-radio QSO logging application. It supports adding, editing, deleting, importing, and exporting QSO records in ADIF format.

The author is amateur radio operator Ivan Yuryev, callsign R1BQE (formerly R1OAZ).

Main window navigation

The main window has two tabs: “Add QSO” and “Journal”. At startup, “Add QSO” is selected, but keyboard focus is on the tab control, not in the Callsign field.

Press Tab to move to the first control on the selected tab. Use Ctrl+Tab and Ctrl+Shift+Tab to switch tabs. When moving from the add form to the Journal tab, focus moves to the records list.

The Tab order within each tab is described below. After the last control on a page, Tab returns navigation to the main tab control.

Add QSO tab

After pressing Tab from the tab control, focus moves to the Callsign field. Subsequent Tab presses move through the visible controls in this order:

  1. Callsign.
  2. Name.
  3. City.
  4. QTH.
  5. Frequency.
  6. RST received.
  7. RST sent.
  8. Mode.
  9. Band.
  10. Comment.
  11. Date.
  12. Time.
  13. Add QSO button.

Fields hidden in settings are skipped. Shift+Tab moves in reverse order.

Enter adds a QSO. Ctrl+Enter looks up the name and city by callsign on QRZ.ru if lookup is enabled. Ctrl+Delete clears the unfinished form; date and time are reset to their current values.

Use the shortcuts in the Keyboard shortcuts section to jump directly to a field or cycle through mode and band values.

Journal tab

When the Journal tab is selected, focus is on the QSO records list. Pressing Tab moves through these controls in order:

  1. QSO records list.
  2. Search field.
  3. Sort field selector.
  4. Sort direction selector.
  5. Filters button.
  6. Main window tab control.

Shift+Tab moves in reverse order. Use Up and Down to move through records. Press Application or Shift+F10 to open the context menu for the selected record.

Search, sorting, and filters

  • Ctrl+F moves focus to the search field. Enter part of a value and press Enter: the list is updated and focus returns to the matching records.
  • Ctrl+Delete in the search field clears the query. Active filters remain enabled.
  • Ctrl+Shift+S moves focus to the sort field selector. Choose the sort direction in the next selector. The preference is saved between runs.
  • Ctrl+Shift+F opens journal filters. You can filter by text fields, bands, modes, date, and time. In the dialog, Alt+R resets, Alt+A applies, Alt+C cancels; Escape closes without applying changes.
  • The Filters button context menu contains a command to clear all filters.

Search and filters determine which records are displayed. Sorting changes only their order. Export marks are retained for records hidden by the current filters.

Marks, editing, and deletion

  • Space toggles the export mark on the selected record. Marked records show “Marked” in the Export column; unmarked rows have a blank cell. NVDA reports the state change.
  • Escape clears all marks.
  • Ctrl+E opens the selected record for editing.
  • Delete deletes the focused record if no records are marked. If any records are marked, all marked records are deleted, including records hidden by filters. Confirmation is required.
  • Ctrl+Z undoes the latest add, edit, or delete operation. The last five actions are available.
  • If editing was started with Ctrl+E, Escape cancels it. The form is cleared, and the next add operation creates a new record.

Settings and Tab order

Press Ctrl+P to open Settings. The dialog has two tabs: “General” and “Interface”. Switch between them with Ctrl+Tab and Ctrl+Shift+Tab.

General tab

Tab moves through the controls in this order:

  1. Operator details: callsign, name, city, QTH, equipment, latitude, longitude.
  2. QRZ.ru callsign lookup: enable checkbox, XML API username, XML API password, show-password checkbox.
  3. Time zone: choose UTC or a custom offset. The offset field becomes available when custom is selected.
  4. Other settings: application logging checkbox, Russian transliteration checkbox, check for updates at startup checkbox.
  5. Save and Cancel buttons.

Interface tab

Tab moves through the controls in this order:

  1. Language: interface language selector.
  2. Theme: system, light, or dark theme selector.
  3. Visible QSO form fields: visibility checkboxes in the order displayed in the group.
  4. Save and Cancel buttons.

Group headings organize related settings and are not separate keyboard focus stops. Press Space to toggle a checkbox. These remain standard Windows checkbox controls.

The theme preview is applied immediately after selection. The language is applied after clicking Save; restarting the program is not required. Save other settings with the Save button.

QRZ.ru lookup

The program can automatically fill in a correspondent’s name and city using the QRZ.ru XML API. This feature requires separate XML API credentials; the regular QRZ.ru website login and password will not work.

To request access, sign in to QRZ.ru, open the XML API settings page, and create an account for BlindLog. After approval, use the supplied username and password.

In Settings → General, enable “Use QRZ.ru” and enter the XML API credentials. Use the show-password checkbox to reveal the password temporarily. After saving, enter a callsign in the QSO form and press Ctrl+Enter. The lookup runs in the background.

Time zone

On the General settings tab, choose UTC or a custom offset from UTC. If you choose a custom value, enter the offset in the adjacent field. This setting is used when working with QSO date and time and during export.

Required fields and visibility

Only the Callsign field is required when adding a QSO. All other fields are optional.

On the Interface tab, the “Visible QSO form fields” group lets you show or hide Name, City, QTH, Frequency, Band, Mode, RST received, RST sent, Comment, Date, and Time. Callsign is always visible and required, so it has no visibility checkbox.

Hiding a field removes it from the add form and its corresponding journal display. Date and Time visibility are independent: if either is hidden, the program uses its current value with the configured time zone. Visibility changes take effect after saving, without restarting the program.

ADIF import and export

To export, use File → Export to ADIF or press Ctrl+S on the Journal tab. If the currently displayed list contains marked records, those marked records are exported. If there are no marks in the displayed list, all records matching the current search and filters are exported.

The suggested filename follows the pattern callsign_date_time.adi. You can change it in the Save dialog.

To import, press Ctrl+O or choose File → Import ADIF. Select an .adi file and choose an import mode:

  • Replace journal — existing records are replaced with records from the file.
  • Append to journal — records are added to existing ones; duplicates are skipped.

After import, the program switches to the Journal tab. The imported fields depend on the contents of the source ADIF file.

Journal storage and backups

QSO records are saved automatically to the SQLite database blind_log.db in the application directory. You do not need to save the journal before exiting. ADIF export creates a separate file for exchanging data with other programs or for backup.

For a full backup, close the program and copy blind_log.db to a safe location. Do not delete this file if you want to keep your journal.

Unfinished form data is saved separately in qso_draft.json and restored at the next launch. If an old blind_log_temp.json file is present, the program may migrate its records into the database at startup; the original file is not deleted automatically.

Program updates

Check for updates from Help → Check for updates or by pressing Ctrl+U. Checking for updates at startup is enabled by default; you can disable it with the checkbox in the “Other settings” group on the General tab.

If an update is available, the program displays the changelog and offers to install it. Exporting the journal before updating is not required: records are stored in blind_log.db, and the updater replaces the executable. You may export to ADIF beforehand if you want an additional backup.

Application log

The “Enable logging” checkbox is in the “Other settings” group on the General tab. When enabled, application actions and errors are written to logs/application.log in the program directory. If that location is not writable, the log is saved under %LOCALAPPDATA%\BlindLog\logs. The updater and installer use separate log files.

Logging is enabled by default and can be disabled with the checkbox. The log is useful for troubleshooting and can be sent to the program author for diagnosis.

Transliteration

The checkbox “Transliterate Russian text to Latin (for LoTW, eQSL, Club Log)” is in the “Other settings” group on the General tab. This feature is disabled by default.

When enabled, Cyrillic text in the Name, City, and Comment fields is converted to Latin. For example, “москва” becomes “moskva”. Text already written in Latin is not changed. ADIF export uses the transliterated values.

Keyboard shortcuts

Main commands

  • Ctrl+P — open Settings.
  • Ctrl+Q — exit.
  • F1 — open Help.
  • Shift+F1 — About.
  • Ctrl+F1 — show the changelog.
  • Ctrl+Tab / Ctrl+Shift+Tab — switch to the next / previous tab.
  • Ctrl+O — import ADIF.
  • Ctrl+S — export ADIF on the Journal tab.
  • Ctrl+U — check for updates.
  • Ctrl+E — edit the selected journal record.
  • Delete — delete the current or marked journal records.
  • Ctrl+Z — undo the latest journal change.
  • Escape — cancel editing or clear journal marks, depending on context.
  • Ctrl+Enter — look up name and city by callsign on QRZ.ru, if enabled.
  • Ctrl+Delete — clear the QSO form or search query, depending on focus.
  • Ctrl+F — focus journal search.
  • Ctrl+Shift+S — focus sorting controls.
  • Ctrl+Shift+F — open journal filters.

Quick navigation in the QSO form

  • Alt+C — Callsign.
  • Alt+N — Name.
  • Alt+T — City.
  • Alt+Q — QTH.
  • Alt+F — Frequency.
  • Alt+R — RST received.
  • Alt+S — RST sent.
  • Alt+O — Comment.
  • Alt+D — Date.
  • Alt+I — Time.
  • Alt+M / Alt+Shift+M — next / previous mode.
  • Alt+B / Alt+Shift+B — next / previous band.

Mode and band cycling wraps around: after the last value comes the first, and before the first comes the last. If a field is hidden, its focus shortcut announces that it is hidden.

Date and time: standard Windows controls are used. Left and Right move between date or time segments; Up and Down change the selected segment.
