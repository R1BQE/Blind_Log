О программе

Blind_Log предназначена для ведения журнала радиосвязей (QSO). Программа позволяет добавлять, редактировать, удалять, импортировать и экспортировать записи QSO в формате ADIF.

Автор программы — радиолюбитель Иван Юрьев, позывной R1BQE (ранее R1OAZ).

Навигация по главному окну

В главном окне две вкладки: «Добавить QSO» и «Журнал». При запуске выбрана вкладка «Добавить QSO», но клавиатурный фокус находится на панели вкладок, а не в поле позывного.

Нажмите Tab, чтобы перейти к первому элементу выбранной вкладки. Для переключения между вкладками используйте Ctrl+Tab и Ctrl+Shift+Tab. При переходе с формы добавления на вкладку «Журнал» фокус устанавливается на список записей.

Порядок элементов внутри каждой вкладки приведён в следующих разделах. После последнего элемента вкладки клавиша Tab возвращает навигацию к панели вкладок.

Вкладка «Добавить QSO»

После перехода с панели вкладок клавишей Tab фокус попадает в поле «Позывной». Далее Tab перемещает фокус по видимым элементам формы в следующем порядке:

  1. Позывной.
  2. Имя.
  3. Город.
  4. QTH.
  5. Частота.
  6. RST принято.
  7. RST передано.
  8. Режим.
  9. Диапазон.
  10. Комментарий.
  11. Дата.
  12. Время.
  13. Кнопка «Добавить QSO».

Скрытые в настройках поля пропускаются. Shift+Tab перемещает фокус в обратном порядке.

Enter добавляет QSO. Ctrl+Enter запускает поиск имени и города по позывному на QRZ.ru, если функция включена. Ctrl+Del очищает незавершённую форму; дата и время сбрасываются на текущие значения.

Для быстрого перехода к отдельным полям и переключения значений режима и диапазона используйте сочетания из раздела «Горячие клавиши».

Вкладка «Журнал»

При переходе на вкладку «Журнал» фокус находится на списке записей QSO. Последовательность перехода клавишей Tab:

  1. Список записей QSO.
  2. Поле поиска.
  3. Список выбора поля сортировки.
  4. Список выбора направления сортировки.
  5. Кнопка «Фильтры».
  6. Панель вкладок главного окна.

Shift+Tab перемещает фокус в обратном порядке. Стрелки вверх и вниз перемещают по записям списка. Для вызова контекстного меню выбранной записи нажмите клавишу Application или Shift+F10.

Поиск, сортировка и фильтры

  • Ctrl+F переводит фокус в поле поиска. Введите часть значения и нажмите Enter: список обновится, а фокус вернётся к найденным записям.
  • Ctrl+Del в поле поиска очищает поисковый запрос. Активные фильтры при этом сохраняются.
  • Ctrl+Shift+S переводит фокус к выбору поля сортировки. Направление сортировки выбирается в следующем списке. Настройка сохраняется между запусками.
  • Ctrl+Shift+F открывает диалог фильтров. В нём можно фильтровать по текстовым полям, диапазонам, режимам, дате и времени. В диалоге доступны Alt+R (сброс), Alt+A (применить), Alt+C (отмена); Escape закрывает диалог без применения изменений.
  • Контекстное меню кнопки «Фильтры» содержит команду сброса всех фильтров.

Поиск и фильтры определяют, какие записи отображаются. Сортировка меняет только порядок записей. Отметки экспорта сохраняются и для записей, скрытых текущими фильтрами.

Отметки, редактирование и удаление

  • Пробел ставит или снимает отметку экспорта у выбранной записи. У отмеченной записи в столбце «Экспорт» отображается «Отмечено», у остальных ячейка пустая. NVDA сообщает об изменении состояния.
  • Escape снимает все отметки.
  • Ctrl+E открывает выбранную запись для редактирования.
  • Delete удаляет запись под фокусом, если отмеченных записей нет. Если есть отметки, удаляются все отмеченные записи, в том числе скрытые фильтрами. Перед удалением программа запрашивает подтверждение.
  • Ctrl+Z отменяет последнее добавление, редактирование или удаление. Доступны последние пять действий.
  • Если редактирование начато сочетанием Ctrl+E, клавиша Escape отменяет его. Форма очищается, а следующее добавление создаёт новую запись.

Настройки и порядок Tab

Откройте настройки сочетанием Ctrl+P. В диалоге две вкладки — «Общие» и «Интерфейс». Переключайтесь между ними сочетаниями Ctrl+Tab и Ctrl+Shift+Tab.

Вкладка «Общие»

Клавиша Tab проходит по элементам в следующем порядке:

  1. Данные оператора: позывной, имя, город, QTH, оборудование, широта, долгота.
  2. Поиск позывных на QRZ.ru: флажок включения функции, логин XML API, пароль XML API, флажок показа пароля.
  3. Часовой пояс: выбор UTC или собственного смещения; при выборе собственного смещения становится доступно поле ввода значения.
  4. Другие настройки: флажок ведения лога, флажок транслитерации русского текста, флажок проверки обновлений при запуске.
  5. Кнопки «Сохранить» и «Отмена».

Вкладка «Интерфейс»

Порядок перехода клавишей Tab:

  1. Язык: список выбора языка интерфейса.
  2. Тема: список выбора системной, светлой или тёмной темы.
  3. Отображаемые поля формы QSO: флажки видимости полей в порядке их расположения в группе.
  4. Кнопки «Сохранить» и «Отмена».

Заголовки групп объединяют связанные настройки и не являются отдельными элементами клавиатурной навигации. Состояние флажка можно изменить клавишей Пробел. Флажки остаются обычными элементами управления Windows.

Тема предварительно применяется сразу после выбора. Язык применяется после нажатия «Сохранить»; перезапуск программы не требуется. Изменения остальных настроек сохраняются кнопкой «Сохранить».

Поиск по QRZ.ru

Функция может автоматически подставлять имя и город корреспондента по позывному с помощью XML API QRZ.ru. Для неё нужны отдельные учётные данные XML API — обычные логин и пароль сайта не подходят.

Для получения доступа войдите в личный кабинет QRZ.ru, откройте страницу настройки XML API и создайте аккаунт для программы BlindLog. После одобрения используйте выданные логин и пароль.

В настройках на вкладке «Общие» включите флажок «Использовать QRZ.ru» и заполните данные XML API. Чтобы временно показать пароль, включите флажок показа пароля. После сохранения введите позывной в форме QSO и нажмите Ctrl+Enter. Поиск выполняется в фоне.

Часовой пояс

На вкладке «Общие» настроек выберите UTC или собственное смещение относительно UTC. При выборе собственного значения укажите смещение в поле рядом с переключателем. Настройка используется при работе с датой и временем QSO и при экспорте.

Обязательные поля и видимость

Для добавления QSO обязательно заполнить только поле «Позывной». Остальные поля необязательны.

На вкладке «Интерфейс» в группе «Отображаемые поля формы QSO» можно скрывать и показывать имя, город, QTH, частоту, диапазон, режим, RST принято, RST передано, комментарий, дату и время. Позывной всегда видим и обязателен, поэтому отдельного флажка для него нет.

Скрытие поля убирает его из формы добавления и соответствующего отображения журнала. Дата и время настраиваются независимо: если одно из полей скрыто, программа использует для него текущее значение с учётом выбранного часового пояса. После сохранения видимость полей обновляется без перезапуска.

Импорт и экспорт ADIF

Для экспорта используйте пункт меню «Файл → Экспорт в ADIF» или сочетание Ctrl+S на вкладке «Журнал». Если в текущем отображаемом списке есть отмеченные записи, экспортируются отмеченные записи из этого списка. Если отметок в отображаемом списке нет, экспортируются все записи, соответствующие текущему поиску и фильтрам.

Имя файла по умолчанию формируется по шаблону позывной_дата_время.adi. Его можно изменить в диалоге сохранения.

Для импорта нажмите Ctrl+O или выберите «Файл → Импорт ADIF». Укажите файл .adi и выберите режим:

  • Заменить журнал — существующие записи будут заменены содержимым файла.
  • Добавить к журналу — записи будут добавлены к существующим; дубликаты пропускаются.

После импорта программа переключается на вкладку «Журнал». Набор импортируемых полей зависит от содержимого исходного ADIF-файла.

Хранение журнала и резервные копии

Записи QSO автоматически сохраняются в базе SQLite blind_log.db в каталоге программы. Перед выходом сохранять журнал вручную не требуется. Экспорт ADIF создаёт отдельный файл для обмена с другими программами или резервной копии.

Для полной резервной копии закройте программу и скопируйте blind_log.db в безопасное место. Не удаляйте этот файл, если хотите сохранить журнал.

Незавершённая форма автоматически сохраняется отдельно в qso_draft.json и восстанавливается при следующем запуске. При наличии старого файла blind_log_temp.json программа может перенести его записи в базу данных при запуске; исходный файл автоматически не удаляется.

Обновление программы

Проверить обновления можно через меню «Помощь → Проверить обновления» или сочетанием Ctrl+U. Автоматическая проверка при запуске включена по умолчанию; её можно отключить флажком в группе «Другие настройки» на вкладке «Общие».

Если доступна новая версия, программа показывает список изменений и предлагает установить обновление. Перед обновлением экспортировать журнал не обязательно: записи хранятся в blind_log.db, а обновление заменяет исполняемый файл. Для дополнительной резервной копии можно заранее экспортировать журнал в ADIF.

Журнал работы программы

Флажок «Вести лог» находится в группе «Другие настройки» на вкладке «Общие». При включённой записи журнал действий и ошибок сохраняется в logs/application.log в каталоге программы. Если каталог недоступен для записи, используется %LOCALAPPDATA%\BlindLog\logs. Файлы обновлятора и установщика ведутся отдельно.

По умолчанию ведение лога включено. Его можно отключить флажком. Лог полезен при диагностике неисправностей: файл можно передать автору программы.

Транслитерация

Флажок «Транслитерировать русский текст в латиницу (для LoTW, eQSL, Club Log)» находится в группе «Другие настройки» на вкладке «Общие». Функция выключена по умолчанию.

Если функция включена, кириллический текст в полях имени, города и комментария преобразуется в латиницу. Например, «москва» преобразуется в «moskva». Текст, уже написанный латиницей, не меняется. При экспорте в ADIF передаются транслитерированные значения.

Горячие клавиши

Основные команды

  • Ctrl+P — открыть настройки.
  • Ctrl+Q — выйти из программы.
  • F1 — открыть справку.
  • Shift+F1 — открыть окно «О программе».
  • Ctrl+F1 — показать историю изменений.
  • Ctrl+Tab / Ctrl+Shift+Tab — переключить вкладку вперёд / назад.
  • Ctrl+O — импортировать ADIF.
  • Ctrl+S — экспортировать ADIF на вкладке «Журнал».
  • Ctrl+U — проверить обновления.
  • Ctrl+E — редактировать выбранную запись журнала.
  • Delete — удалить текущую или отмеченные записи журнала.
  • Ctrl+Z — отменить последнее изменение журнала.
  • Escape — отменить редактирование или снять отметки в журнале в зависимости от текущего контекста.
  • Ctrl+Enter — найти имя и город по позывному на QRZ.ru, если функция включена.
  • Ctrl+Del — очистить форму QSO или поисковый запрос в зависимости от текущего фокуса.
  • Ctrl+F — перейти к поиску в журнале.
  • Ctrl+Shift+S — перейти к настройке сортировки.
  • Ctrl+Shift+F — открыть фильтры журнала.

Быстрый переход по форме QSO

  • Alt+C — позывной.
  • Alt+N — имя.
  • Alt+T — город.
  • Alt+Q — QTH.
  • Alt+F — частота.
  • Alt+R — RST принято.
  • Alt+S — RST передано.
  • Alt+O — комментарий.
  • Alt+D — дата.
  • Alt+I — время.
  • Alt+M / Alt+Shift+M — следующий / предыдущий режим.
  • Alt+B / Alt+Shift+B — следующий / предыдущий диапазон.

Переключение режима и диапазона циклическое: после последнего значения выбирается первое, а перед первым — последнее. Если поле скрыто, сочетание перехода к нему сообщает об этом.

Дата и время: используются стандартные элементы выбора Windows. Стрелки влево и вправо перемещают между сегментами даты или времени, стрелки вверх и вниз меняют значение выбранного сегмента.
