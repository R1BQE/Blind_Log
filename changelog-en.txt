Version 4.12.1
- Fixed Windows language auto-detection: with the "auto" setting the changelog now appears in the same language as the interface. The Windows UI language is read directly via GetUserDefaultUILanguage.
- Changelog history split into two files: changelog-ru.txt and changelog-en.txt. The English translation was corrected into proper English.
- The program description in the executable properties is now in English.
- Reworked release publishing: the version is taken from the git tag or entered in the run form, the tag is created automatically. The release description is in English with a link to the Russian changelog.
- The update check now shows the changelog in the correct language from the repository.

Version 3.4.11
- Fixed the repository URL in the update checker — the program now correctly receives information about new versions.
- Swapped Enter and Ctrl+Enter: Enter now adds a QSO, Ctrl+Enter performs a QRZ.ru lookup. The lookup now works from any field in the form, not only the callsign field.
- Added canceling of record editing with the Escape key. If you started editing a QSO but changed your mind — press Escape, the form will be cleared and the editing mode will be dropped. NVDA will announce the confirmation.
- Added a "Feedback" submenu to the "Help" menu with "Write to email" and "Write to Telegram" items.
- Fixed several technical issues: unified reading of the autosave setting, corrected QRZ.ru error handling, replaced the outdated system language detection function.
- Updated the help: new features described, hotkeys corrected, contacts section updated.
