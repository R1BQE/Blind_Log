# MISTAKES.md

- `gui.py` содержит часть логики формы и выборки данных, что усложняет разделение UI и контроллера.
- Некоторые исключения перехватываются слишком широко (`except Exception`), особенно в UI и менеджере.
- Настройки `SettingsDialog.on_language_change` перезагружает переводы без немедленного применения всех UI элементов.
- `QSOManager.add_qso` выполняет частичную валидацию и нормализацию, что делает метод длинным.
- `updater.py` смешивает сетевые запросы и UI-диалоги в одном модуле.
- `nvda_notify.py` использует `print()` в рабочем коде вместо чистого логирования.
