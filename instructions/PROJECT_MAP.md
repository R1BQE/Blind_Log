# Карта проекта Blind_Log

Blind_Log — настольный журнал радиолюбительских QSO на Python и wxPython. Интерфейс рассчитан на работу с клавиатуры и совместимость с NVDA.

## Структура исходников

- `main.py` — точка входа и запуск приложения.
- `gui/` — главное окно и его UI-компоненты; `gui/welcome_dialog.py` — приветственное окно.
- `controller/` — контроллер приложения и действия, вызываемые интерфейсом.
- `journal/` — логика журнала QSO, операции и SQLite-хранилище.
- `settings/` — менеджер настроек, чтение/запись и диалог настроек.
- `adif/` — импорт и экспорт ADIF.
- `services/` — QRZ lookup и сервисы обновления.
- `common/` — общие утилиты, константы, транслитерация, changelog и работа с версией.
- `localization/` — загрузчик переводов.
- `locales/` — JSON-файлы переводов. Они оставлены в корне проекта, чтобы сохранить совместимость с текущей упаковкой.
- `accessibility/` — уведомления NVDA.
- `help/` — локализованная HTML-справка.
- `instructions/` — документация для разработки и AI-помощников.
- `tests/` — pytest-тесты.
- `scripts/` — вспомогательные скрипты.

## Файлы, которые остаются в корне

- `settings.ini` — пользовательские настройки, создаётся при запуске и не хранится в Git.
- `blind_log.db` и файлы черновиков — пользовательские данные, создаются во время работы.
- `version.txt`, `requirements.txt`, `Blind_log.spec`, `updater.spec`, `compile.bat` — версия, зависимости и сборка.
- `readme.md`, `readme_ru.md` — страницы проекта для GitHub.
- `AGENTS.md` — корневые инструкции для инструментов разработки; оставлен здесь, потому что агенты обычно ищут его в корне.

Старые имена модулей сохранены в виде совместимых точек импорта там, где это нужно существующему коду и тестам. Новые изменения следует вносить в модули внутри соответствующих пакетов.
