# GLOSSARY.md

QSO — запись о радиосвязи в журнале.
ADIF — Amateur Data Interchange Format, стандарт обмена данными радиолюбительских журналов.
QRZ — база данных позывных; в проекте используется XML API QRZ.ru.
NVDA — экранный диктор для Windows.
Screen reader — программа экранного доступа, озвучивающая интерфейс и его состояние.
Band — радиолюбительский диапазон.
Mode — вид радиосвязи или модуляции, выбираемый в поле режима.
Callsign — позывной радиостанции.
Grid Locator / QTH — координатный радиолюбительский локатор. В Blind_Log поле `qth` хранит локатор, а `city` — город корреспондента.
LoTW — Logbook of The World, сервис подтверждения радиосвязей, использующий данные ADIF.
Club Log — онлайн-журнал радиосвязей, поддерживающий импорт ADIF.
eQSL — сервис электронных QSL-карточек.
GUIBridge — интерфейс взаимодействия контроллера и графического интерфейса.
QSOManager — менеджер бизнес-логики и данных QSO.
ApplicationController — координатор между GUI и менеджером QSO.
SettingsManager — менеджер загрузки и сохранения настроек.
Exporter — модуль экспорта записей в ADIF.
Importer — модуль импорта ADIF во внутренний формат QSO.
Updater — компоненты проверки и установки обновлений из GitHub Releases.
Theme — схема оформления интерфейса: светлая, тёмная или системная.
Date/time segment — отдельная редактируемая часть нативного поля даты или времени.
Translation / `tr(...)` — функция получения локализованной строки.
