Версия 3.4.11
- Исправлен URL репозитория в модуле проверки обновлений — программа теперь корректно получает информацию о новых версиях.
- Поменяны местами клавиши Enter и Ctrl+Enter: Enter теперь добавляет QSO, Ctrl+Enter — поиск по QRZ.ru. Поиск теперь работает из любого поля формы, а не только из поля позывного.

- В меню «Помощь» добавлено подменю «Обратная связь» с пунктами «Написать на почту» и «Написать в Телеграм».
- Устранено несколько технических проблем: унифицировано чтение настройки автосохранения, исправлена обработка ошибок при работе с QRZ.ru, заменена устаревшая функция определения языка системы.
- Обновлена справка: описание новых возможностей, исправлены горячие клавиши, обновлён раздел контактов.
